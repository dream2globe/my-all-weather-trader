# My All-Weather Trender (Dynamic Pension Portfolio)

본 프로젝트는 퇴직연금(IRP) 및 개인연금 계좌에서 운용하기 위한 **동적 자산 배분 및 가치평균법(Value Averaging) 자동화 백테스트 엔진 및 실전 투자 파이프라인**입니다.

## 🌟 핵심 전략 v3.0 (Core Strategies)
1. **Value Averaging (가치평균법)**: QQQ, KOSPI, VEA, COPPER, TLT, GLD, SHV 자산에 대해 매월 정해진 목표 복리 성장률(Target Growth Rate) 단가를 추종합니다.
   * 목표치보다 평가액이 부족하면 추가 매수, 초과하면 '초과분의 절반(50%)'만 매도하여 수익을 실현합니다.
   * 상승 랠리 시 곧바로 매도하지 않도록 KOSPI 등에 +5% 허용 밴드(Tolerance Band)를 적용합니다.
   * **현금 고갈 방어(Dynamic Max Cap)**: 자산 동반 급락 시 현금이 광속 고갈되는 것을 막기 위해, 각 전략의 1회 매수 상한선을 전체 자산 비율이 아닌 '해당 자산 배분액의 5%'로 대폭 리스크를 제한했습니다.
   * 달마다 시드머니가 분할 투입되는 월단위 적립식 투자 시나리오(동적 타겟 자동 우상향)를 완벽하게 지원합니다.
   * **동적 롤링 윈도우 적용**: 시스템이 스스로 반기마다 최근 과거 데이터를 학습하여 VA 월 목표 성장률을 동기식으로 갱신합니다.
2. **글로벌 주식 포트폴리오 (50%)**: QQQ(25%), KOSPI(15%), 선진국 VEA(10%)를 편입하여 주식형 수익을 창출합니다.
3. **구조적 인플레이션 방어선 구축 (40%)**: 고물가 장기화 및 지정학적 리스크에 대비하여 원자재 비중을 늘렸습니다. 산업용 원자재 COPPER(10%), 금 GLD(15%)를 전진 배치하고 장기채 TLT(5%) 비중을 대폭 줄였습니다. 절대 무손실 방어선인 초단기채 SHV(10%)가 달러 파킹을 담당합니다.
4. **암호화폐 독립 운용**: 비트코인(BTC)과 이더리움(ETH)은 연금 시스템 시스템 외부에서 별도로 직투 관리하기 위해 본 포트폴리오 비중에서 완전히 배제(0%) 하였습니다. 대신 인플레이션 헷지용 원자재와 위기 투입용 대기 현금 10%를 방어 패드로 사용합니다.
5. **매크로 오버라이드 시스템 (Macro Overrides)**: 중동/지정학적 리스크, 금리 인상, 인플레이션 등 거시경제 충격 발생 시, 코드를 건드리지 않고 `macro_config.json` 설정을 통하여 대상 자산의 매수/매도 비율을 즉각적으로 컨트롤 할 수 있도록 시스템화했습니다.

## ⚙️ 설치 및 실행 방법

### 1단계: 환경 설정 (`uv` 패키지 매니저 권장)
```bash
# 가상환경 생성 및 활성화
uv venv .venv
source .venv/bin/activate

# 의존성 패키지 초고속 설치
uv pip install -r requirements.txt
```

### 2단계: 백테스트 시뮬레이션 엔진 구동
`run_backtest.py`를 실행하여 포트폴리오 유니버스의 전체 과거 데이터를 백테스트하고, 타겟 최적화 수준을 점검합니다. 
```bash
python run_backtest.py
```

### 3단계: [중요] 실전 계좌 연동 매매 계획 산출 (`run_live_plan.py`)
실제 연금 계좌의 체결 내역을 바탕으로 매주 현황에 맞춘 '실행 리포트'를 도출합니다.
1. 평소 체결했던 매매 내역을 `data/actual_trades.csv` 표에 한 줄씩 이력으로 입력합니다.
   * **형식**: `Date,Ticker,Action,Price,Quantity,Name` 
2. 특정 매크로 리스크 대처가 필요한 경우 `macro_config.json`의 해당 자산군 비율(`override_ratio`)을 능동적으로 조절합니다.
3. 아래 명령어를 실행하여 최종 액션 아이템이 담긴 마크다운 리포트를 뽑아냅니다.
```bash
python run_live_plan.py
```
엔진 실행이 정상 종료되면, `reports/live_trade_plan_YYYYMMDD.md` 파일 명으로 이번 주 얼마의 비율로 각 종목을 사고 팔지 정리된 보고서가 자동 생성됩니다.

### 4단계: (선택) 단위 테스트(Unit Test)를 통한 검증
각 모듈(엔진 체결기 및 시그널 생성기)의 안전성을 독립적으로 검증합니다.
```bash
pytest tests/ -v
```

## 📅 매주 주말 정기 점검 가이드 (Weekly Check-up Routine)

본 시스템은 가치평균법을 기반으로 작동하므로 매일 계좌를 들여다볼 필요가 없으며, 시스템 산출을 맹신하지 않고 거시 환경을 반영해 유연하게 조율합니다.

1. **이번 주 체결 내역 업데이트**: 평일 동안 IRP 계좌에서 발생한 실제 매수/매도/배당금 내역을 `data/actual_trades.csv`에 입력합니다. 최신 종목 이름(`name` 열) 등 기록 포맷 준수에 주의하세요.
2. **실전 매매 계획 리포트 생성**: 가상 환경(`source .venv/bin/activate`) 상태에서 `python run_live_plan.py` 실행! 
   * 최신 주가를 긁어와 현재 계좌 평가액을 즉시 계산하고 차주 월요일 목표 궤도와의 갭(Gap)을 산출합니다.
3. **리포트 확인 및 예약 매수**: 
   * 생성된 리포트 하단의 **[리스크 오버라이드 반영 최종 매매 지시]** 액션 테이블을 확인합니다.
   * 엔진의 권고 수치와 `macro_config.json`에 기입된 나의 판단(비중 조절)이 합산된 지시 금액에 맞춰, 월요일 증권사 앱을 통해 국내 대체 ETF 물량을 매매(혹은 예약 진입) 합니다.
